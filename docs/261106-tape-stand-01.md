## 1. What it is

**Tape** (working name) is Maik's native macOS audio editor. Final Cut Pro feel: record from any input in any format, cut, fade, process, export in any format. One user, Apple Silicon, no cloud. Built by a Cursor agent from the spec, one milestone at a time, with Maik's OK between milestones.

## 2. Document and engine

- `.tape` package: `project.json` (versioned), `sources/` (recordings and consolidated imports as CAF float32), `peaks/` (pyramid cache, rebuilt if missing). Imports referenced by bookmark until consolidated. Autosave 500 ms, crash recovery.
- One track of regions `{source, in, out, position, gain, fadeIn, fadeOut}`, fade shapes linear, S, log, exp with blend. Non-destructive: trim, move, gain, fades never touch sources. Processing renders a new source and repoints the region, the old source stays for undo until Clean Up Sources.
- **One renderer for playback and export.** `EditListRenderer` pulls any time range from the edit list; playback through an `AVAudioSourceNode`, export through manual rendering mode. No second fade code path.
- Peak pyramid (block 16, 256, 4096, 65536, Float16 min/max) built with vDSP off the main thread. Metal draws one column per pixel from the nearest level, exact samples below 1 sample per pixel.
- **Record:** CoreAudio device list, device set on the input node (system default untouched), any channel subset, 16/24/32f, WAV/AIFF/CAF/FLAC, pre-roll ring buffer 0 to 60 s (default 10) so R catches what happened before the key press, dedicated writer queue, dropout counter, meters with peak hold.

## 3. Features (M1 to M5 done)

- **Edit:** FCP keys (Space, JKL, I/O, Cmd B blade, Delete ripple, Forward Delete gap, Cmd D, F default fade, Option Cmd F fade dialog, Shift Z fit, comma and period nudge). Trim with zero-crossing and edge snapping, fade handles on region corners with live audio while dragging, range selection, rubber band.
- **Process** (preview, apply, undo): normalize peak or integrated LUFS (BS.1770-4, true peak 4x), gain, DC offset, trim silence, reverse, compressor (`AUDynamicsProcessor`), limiter (`AUPeakLimiter`), resample. Generic `AUProcess` wrapper, any Apple AU is one line.
- **Export:** WAV, AIFF, CAF, FLAC, ALAC, AAC; 44.1 to 192 kHz; TPDF dither to 16 bit; scope document, range, selection, each region with naming pattern; hardware presets from PolyTracker (Morphagene, Octatrack, Digitakt, SP-404); progress and cancel; export equals playback render.

## 4. Decisions

- Processing is apply-and-render per region, not a live per-region AU chain. Keeps one render path.
- Record rate is the device rate; conversion only on export or as an explicit process.
- Fades and gain are non-destructive, everything else renders a new source.
- Multitrack is a view and a mix, not a second document type (M6 below).
