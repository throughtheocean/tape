# Tape v2 ideas

Ideas that came up while building and are not in the spec.

- Open Recent menu for `.tape` packages.
- App Sandbox with security-scoped access around every source read.
- Show audible play start latency (including output device latency) in the inspector.
- Waveform colour per region, and region names that follow the visible part of a long region.
- Peak build progress in the timeline placeholder for very long files.
- Sub frame ruler labels in timecode style (frames plus subframes, as Final Cut Pro shows them) instead of milliseconds.
- Restore the previous selection on undo of delete and duplicate.
- Draw waveforms with region gain and fades applied.
- Delete with a range set and no selection removes the range (ripple), like Final Cut Pro's range delete.
- Slip edit (move the source under a fixed region) with Option drag.
