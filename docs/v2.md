# Tape v2 ideas

Ideas that came up while building and are not in the spec.

- Open Recent menu for `.tape` packages.
- App Sandbox with security-scoped access around every source read.
- Show audible play start latency (including output device latency) in the inspector.
- Waveform colour per region, and region names that follow the visible part of a long region.
- Peak build progress in the timeline placeholder for very long files.
- Sub frame ruler labels in timecode style (frames plus subframes, as Final Cut Pro shows them) instead of milliseconds.
- Restore the previous selection on undo of delete and duplicate.
- Draw waveforms with region gain and fades applied.
- Delete with a range set and no selection removes the range (ripple), like Final Cut Pro's range delete.
- Slip edit (move the source under a fixed region) with Option drag.
- Process to the source's own format (16 or 24 bit) instead of float32 CAF, to keep package size down.
- Loudness meter (momentary, short term, integrated, LRA) in the inspector for the range or selection.
- Remove DC with a high-pass option for drifting offsets.
- Normalize with an automatic limiter step when the true peak ceiling would hold the loudness back.
- Chain export: Morphagene reels with CUE splice markers per region and Octatrack chains with the `.ot` slice file (PolyTracker has `WAVCueWriter` and `OTFileWriter`).
- User-defined export presets (PolyTracker's custom preset store).
- Reveal in Finder after an export.
- Pan law choice per document (-3 dB or 0 dB centre), see M6 deviation 1.
- Option click on S for exclusive solo, and Option click on M to mute all others.
- Minimap regions tinted by track color in the multitrack view.
- Drag a file from Finder onto a lane to import it onto that track at the drop position.
- Track names in the region strip of the single view.
- Loudness range (LRA) and maximum true peak in the loudness column, as more readings for the switch button.
- Loudness history graph (short term over time) for the played part.
- Per-track lane height with a drag handle on the lane's lower edge.
- Save the export start number with the document, so numbering continues after reopening.
