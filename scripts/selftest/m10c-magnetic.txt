# M10c: track 1 magnetic with three regions, track 2 free with a region connected to the middle one.
# a = tape-m6-a (192000), b = tape-m6-b (144000).
wait 1
import /tmp/tape-m6-a.wav
waitLoaded
view 0 500
key cmd+shift+m
key cmd+t
drop opt f240000 lane1 /tmp/tape-m6-b.wav
drop opt f480000 lane1 /tmp/tape-m6-a.wav
drop f300000 lane2 /tmp/tape-m6-b.wav
waitLoaded
log start: track 1 a 0, b 240000, a 480000 with gaps; x (b) on track 2 at 300000
header 1 click magnet
log magnetic on: gaps closed to a 0, b 192000, a 336000; x stays; undo 'Close Gaps'
mouse down f50000 wave:1
mouse drag f98000 wave:1
mouse up f98000 wave:1
log first region dragged 1 s later: a 48000, b 240000, a 384000, magnetic from 48000
key cmd+z
mouse down f350000 wave:2 opt+cmd
mouse drag f300000 wave:1 opt+cmd
log Option Command drag of x over b: x at 250000, b outlined
snapshot /tmp/tape-m10c-connect-drag.png
mouse up f300000 wave:1 opt+cmd
log connected: x anchored to b +58000, undo 'Connect'
snapshot /tmp/tape-m10c-connected.png
mouse down f191500 wave:1
mouse drag f144000 wave:1
mouse up f144000 wave:1
log trim a's end to 144000: b 144000, a 288000, x 202000 (all 48000 left)
mouse down f200000 wave:1
mouse drag f20000 wave:1
log dragging b to the front: insertion at 0, the others slid apart
snapshot /tmp/tape-m10c-reorder-drag.png
mouse up f20000 wave:1
log reordered: b 0, a 144000, a 288000; x follows b to 58000
mouse down f200000 wave:1
mouse drag f500000 wave:1
log dragging the first a past the middle of the second: b 0, a 144000, dragged a 336000, insertion line at 336000
snapshot /tmp/tape-m10c-reorder-end.png
mouse up f500000 wave:1
key cmd+z
mouse click f20000 wave:1
key fwddelete

snapshot /tmp/tape-m10c-gap.png

mouse click f20000 wave:1
key delete

key cmd+z
log undo: b back, x connected again
drop f150000 lane1 /tmp/tape-m6-b.wav
waitLoaded
log drop at 150000 on the magnetic lane: inserted between b (middle 72000) and a (middle 216000) at 144000
key cmd+z
header 2 click body
header 2 click magnet

sheet escape

sheet return

key cmd+z
key cmd+z
log undo twice: track 2 free, x connected at 58000
header 1 click body
key cmd+shift+m
log single view, track 1
snapshot /tmp/tape-m10c-single.png

log Shift Command G: track 1 magnetic off, positions and the connection kept
